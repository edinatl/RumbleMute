# RumbleMute privacy policy

_Last updated: November 5, 2026_

RumbleMute is a browser extension that hides chat messages from usernames you choose on Rumble livestreams.

## What it stores

The extension saves the following **only on your own computer**, in Chrome's local extension storage (`chrome.storage.local`):

- The usernames you block or mute, and when each mute ends
- How many messages from each listed user have been hidden, plus a running total
- The ids of recently hidden chat messages, so the same message is not counted twice
- Your settings (whether filtering is on, and how the block list is sorted, and whether the popup uses light, dark, or your system's theme)

## What it does not do

- It does not collect, transmit, sell, or share any data. It makes no network requests.
- It has no analytics, tracking, advertising, or remote code.
- It does not read your Rumble account, cookies, or browsing history.
- It runs only on `rumble.com` pages. There it reads chat usernames and message ids so it can hide matching rows. Nothing it reads leaves your browser.

## Removing your data

Remove usernames from the extension popup, or uninstall the extension. Uninstalling deletes everything it stored.

## Contact

Questions about this policy can be raised as an issue on the project's GitHub repository.
